# Content Drafts

These files are drafts the owner will paste into the admin dashboard's
Projects manager. They are intentionally **incomplete**: every fact that
would need research, a customer number, a duration, or a metric is
left as a `TODO(<note>)` placeholder so nothing is invented.

When filling these in:

1. Open `/admin/projects` in the dashboard.
2. Click **New Project** or edit an existing one.
3. Paste the contents of the relevant `summary`, `description`,
   `architecture`, `challenges`, `lessons_learned`, and `future_plans`
   fields.
4. Replace every `TODO(...)` line with a real, verified fact. If a
   number cannot be verified, delete the line entirely — never make
   one up.

Files in this directory:

- `aion.md` — the **aion** case study (AI/PLATFORM category).
- `devconnect.md` — the **DevConnect** case study (AI/PLATFORM category).
- `fixes-to-existing-text.md` — short edits to the prose already
  shipped for the hero / about sections.
